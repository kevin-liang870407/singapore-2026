# 新加坡 × 迪士尼郵輪 旅遊帖

2026 年 11 月新加坡自由行與迪士尼郵輪的行程網頁,手機優先,單一 HTML 檔製作。

🔗 網站:https://kevin-liang870407.github.io/singapore-2026/

## 功能

- **首頁**:出發倒數與航班資訊
- **行程**:依日期切換的每日時間軸,可自行新增、編輯、刪除,並加上備註與圖片
- **郵輪**:Disney Adventure 介紹(餐飲、表演、設施),每個視窗都能編輯
- **清單**:待辦、託運行李、隨身行李,可打勾
- **住宿**:住宿與艙房資訊,可自行新增視窗

## 使用說明

- 所有修改(行程、備註、圖片、勾選)都只存在該裝置的瀏覽器中,換裝置或清除瀏覽器資料就會消失。
- 手機建議用瀏覽器的「加入主畫面」,使用起來像 App。

## 更新網站

到 repo 用 Add file → Upload files 上傳新的 `index.html`(同名會覆蓋),等 1–2 分鐘即可更新。
